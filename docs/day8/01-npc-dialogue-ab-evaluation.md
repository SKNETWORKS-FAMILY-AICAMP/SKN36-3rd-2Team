## 6. 보안 검토

기존 A/B 평가의 보안 질문은 각 20건 모두
출처 없는 Fallback으로 처리되었다.

확장 평가의 보안 질문도 수정 전후 각각
6건 모두 출처 없는 Fallback으로 처리되었다.

최초 기억 기능은 과거 NPC 응답이나
플레이어의 임의 입력을 그대로 반환하지 않는다.

증거 제시 Pilot의 C03 EV10에서는
이미 수집하고 제시한 증거의 출처가 반환되었다.

확인한 응답 부분에서는 미획득 증거 및
사건 정답의 직접적인 노출이 발견되지 않았다.

전체 응답 및 출처 권한에 대한 추가 보안 검증은
#181에서 수행한다.

- Grounded 응답 여부만으로 답변 관련성과 사실 정확성을

- 검색 및 문맥 관련 결함은 #179에서 추가 분석한다.
