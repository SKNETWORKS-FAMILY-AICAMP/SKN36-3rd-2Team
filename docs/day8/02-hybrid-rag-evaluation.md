# Day 8 — Hybrid RAG 및 NPC 자연어 대화 고도화

## 1. 작업 개요

기존 키워드 중심 NPC 대화를 의미 기반 자연어 대화로 확장하고,
Hybrid RAG 검색 안정성, 대화 문맥, 근거 검증 및 영구 저장을 개선한다.

## 2. 주요 구현

### 2.1 Hybrid RAG 검색 안정화

- BM25 검색 가능 토큰이 없는 입력에 대한 예외 처리
- 검색 토큰 부재 시 Sparse 결과만 비활성화
- Dense 및 Graph 검색 경로 유지
- 기존 접근 정책 및 신뢰 원문 검증 유지
- 의미 기반 검색어 보강
- 현재 NPC 및 게임 상태 기반 검색 범위 유지

### 2.2 대화 문맥 개선

- 최근 대화에 기반한 검색어 확장
- 의미가 유사한 질문 및 반복 질문 처리
- 이전 검증 답변의 현재 접근 권한 재확인
- 무관한 중복 답변과 정상적인 재확인 요청 구분
- 직전 진술이 없는 후속 요청에 대한 clarification 처리

### 2.3 Semantic Intent Router

- 인사, 대화 요청, 감사, 작별, 안부 분류
- 자기소개, 인물 관계, 사건 조사 분류
- 개인 취향 및 감정 질문 분류
- 후속 질문과 추가 설명 요청 구분
- 최초 및 직전 대화 기억 요청 처리
- 비공개 정보 및 규칙 우회 요청 차단

### 2.4 Semantic Relevance Guard

- 선택된 근거와 사용자 질문의 관련성 검증
- DIRECT, PARTIAL, REJECT 분류
- 관련성이 없는 사건 진술 차단
- 이전 진술의 출처 및 접근 범위 재검증
- 검증 실패 시 안전한 Fallback

### 2.5 NPC 자연어 렌더링

- NPC별 기존 말투 설정 재사용
- 검증된 원본 인용문과 화면 대사 분리
- 외부 JSON 대사 카탈로그 로딩
- SHA256 무결성 검사
- 콘텐츠 및 릴리스 버전 일치 검사
- NPC와 근거 ID 일치 검사
- 위조 대사 및 타 NPC 대사 차단

## 8. DB 영구 저장 및 기억

현재 SQLite 저장소를 유지한다.

- npc_sessions: NPC 세션 및 Revision
- npc_exchanges: 질문, 검증 답변, 출처, Revision, 화면 대사
- game_states: 게임 진행 상태

검증 결과:

- 기존 게임 DB: 54개 세션, 203개 대화
- 확장판 기본 DB: 검사 시점 기준 대화 0건
- 기존 DB 스키마 및 데이터 보존
- 저장소 재연결 후 기억 복원 검증
- 최초 및 직전 질문의 안전한 요약
- 다른 세션 및 NPC 기억 접근 차단
- 원자적 대화 저장 및 Rollback 검증
- DB 관련 기존 테스트 39개 통과

대화 평가 스크립트는 인메모리 저장소를 사용한다.
실제 저장 검증은 별도의 임시 SQLite DB에서 수행한다.

현재 NPC별 최근 50턴 보존 제한을 유지한다.
실제 최초 대화의 장기 보존 및 관련 과거 대화 검색은 후속 구현 대상이다.

PostgreSQL 및 AWS RDS 전환은 별도 이슈로 진행한다.

## 10. 운영 및 보안 제한

기본 설정에서는 의미 기반 대화와 파일럿 대사 기능을 활성화하지 않는다.

- CRIMESCENE_ENABLE_SEMANTIC_DIALOGUE=false
- CRIMESCENE_ENABLE_PILOT_SPEECH=false

다음 로컬 실험용 설정은 운영 환경에 전달하지 않는다.

- CRIMESCENE_LOCAL_SPEECH_CATALOG
- CRIMESCENE_LOCAL_SPEECH_SHA256

추가 검증 필요:

- 모델 관련성 판단 오류 및 분류 우회
- 의미 기반 일상 응답과 실제 질문 간 바인딩 강화
- 대화 기억의 오염 및 권한 회귀
- 카탈로그 변경에 따른 저장 대사 재검증
- 콘텐츠 승인 및 배포 권한 분리
- 복합 질문과 반복 질문의 일관성
- 모든 챕터의 실제 콘텐츠 검증

이번 평가의 보안 질문 40건 차단은 제한된 공격 사례에 대한 결과이며
전체 공격에 대한 안전성을 보장하지 않는다.
