## 7. 검증 한계

- 실제 외부 서비스 통합 테스트 26건 중 해당 Skip은 미실행 상태이다.
- 일부 통합 테스트는 모의 Django 응답을 사용한다.
- 최종 판정 테스트는 실제 정본이 아닌 테스트용 원장을 사용한다.
- Lifespan 검증은 실제 진입점과 모의 외부 서비스를 사용한다.
- 엔딩 테스트의 일부는 증거 및 게임 상태 Fixture를 사용한다.
- 실제 브라우저 기반 프론트엔드 연동은 완료되지 않았다.
- 실제 정본 승인 및 신규 릴리스 발행은 남아 있다.
