## 8. 로컬 환경 주의사항

확장판 Django는 다음 기존 DB를 사용하여 검증하였다.

    .local/case001_1120_release/issue165.sqlite3

확장판 서비스 토큰:

    .local/case001_1120_release/service-token.txt

해당 파일의 실제 값은 출력하거나 커밋하지 않는다.

읽기 전용 Django 검증 서버는
릴리스 발행용 쓰기 환경과 구분한다.

FastAPI와 Django의 Python 환경을 혼용하지 않는다.

기존 미추적 E26 감사 문서는
관련 없는 커밋에서 제외하고 보존한다.
