# api 디렉터리

FastAPI 통신, 요청·응답 타입 및 Mock API.

## 파일 구성

| 파일 | 역할 |
|---|---|
| [`client.ts`](./client.ts) | 게임 API 클라이언트 구성 |
| [`httpApi.ts`](./httpApi.ts) | 실제 FastAPI HTTP 통신 구현 |
| [`mockApi.ts`](./mockApi.ts) | 백엔드 없이 동작하는 Mock API 구현 |
| [`types.ts`](./types.ts) | API 요청·응답 및 게임 데이터 타입 |
