# store 디렉터리

Zustand 기반 클라이언트 상태 관리.

## 파일 구성

| 파일 | 역할 |
|---|---|
| [`chatStore.ts`](./chatStore.ts) | NPC 채팅 관련 클라이언트 상태 |
| [`gameStore.ts`](./gameStore.ts) | 게임 세션, 진행 상태 및 화면 연동 상태 |
| [`noteStore.ts`](./noteStore.ts) | 플레이어 메모 관련 클라이언트 상태 |
